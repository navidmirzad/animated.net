# 🎌 Animated.NET

**Your go-to anime database**

Animated.NET is a project built with the purpose of sharpening our skills in **C# .NET** and **React.js** — and what better way to learn than by combining our favorite pastime with our actual work!

---

## About the Project

Animated.NET is heavily inspired by [MyAnimeList](https://myanimelist.net/), and was created as a hands-on learning platform to improve our understanding of:

- System integration  
- Scalability & performance  
- UX & UI design  

the goal is to build a clean, responsive, and efficient anime database experience while strengthening our real-world development skills.

---

## Architecture & Tech Stack

For now, Animated.NET is built as a **monolithic application**, consisting of:

- **Backend:** C# / .NET  
- **Frontend:** React.js  
- **Database:** MariaDB

---

## Future Goals

One of our long-term objectives is to evolve this project into a **microservice architecture**, with the aim of achieving:

- Greater scalability  
- Improved system resilience  
- High availability (uptime)  
- Fault tolerance  
- Better separation of concerns
